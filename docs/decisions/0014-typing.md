# 0014 — 타이핑: 글 안 표시와 글자 소리

2026-09-27 · 여섯 번째 이야기(당근 도둑) 설계(구현 전) · 고치는 비용: **비쌈** (대사 글 안의 표시 문법과 NPC 문서의
`voice` 칸이 저장된다. 첫 공개 전이라 지금은 초기화로 쌈)

## 장면

> 농부에게 말을 걸면 대사가 한 글자씩, 농부의 낮고 투박한 목소리와 함께 나온다. "이 밭 좀 보게……"는 천천히, 밭을
> 가리키며, "……"에서 잠깐 멈춘다. 같은 페이지에서 "헉, 토끼들이 당근을 다 파먹었잖아!"는 빠르게, 놀라며. 경비대장은
> 높고 딱딱한 다른 목소리로 말한다.

전체 장면은 [stories.md](../stories.md) "여섯 번째 이야기".

## 글 안 표시: 꺾쇠 `<…>`

```
<loop=animation.chief.point><speed=0.5>이 밭 좀 보게<pause=1>……<speed=2><play=animation.chief.shocked>헉, 토끼들이 당근을 다 파먹었잖아!
```

- **꺾쇠 = 대화창 연출**(대사에서만 뜻이 있다). **중괄호는 값 넣기 자리로 남겨 둔다**: 나중의 `{player}`, 그래프의
  값 끼워 넣기(옛 `legacy-v2`의 `Format Text`가 `{name}`을 입력 포트로 썼다). 대사와 채팅 어디서나 같은 뜻이 되게.
- `<` 바로 뒤에 영어 글자가 올 때만 표시다. 그래서 "A < B", "<-", "<3"은 글자 그대로. 모르는 표시 이름은 publish 거부.
- **닫는 표시가 없다**: 표시는 "여기서부터 그 페이지 끝까지"(또는 같은 표시가 다시 나올 때까지). 페이지가 넘어가면 기본으로.
- 논리(조건·계산)는 담지 않는다. 0012가 버린 "글자 식 조건"과 달리 위치 신호를 나열할 뿐이다.

| 표시 | 뜻 |
|---|---|
| `<speed=배수>` | 여기서부터 글자 속도. 1 = 기본, 0.5 = 절반. 0보다 크고 10 이하 |
| `<pause=초>` | 여기서 멈춤. 0~10초, 소수 가능 |
| `<play=애니메이션>` | 여기서 동작 한 번(이름은 `animation` 칸과 같은 전체 이름) |
| `<loop=애니메이션>` | 여기서부터 동작 반복(페이지가 넘어가면 멈춤) |
| `<voice=none>` | 여기서부터 소리 없음(언더테일의 해설처럼) |
| `<voice>` | 여기서부터 원래 목소리 |

- 줄 전체의 `animation` 칸([0009](0009-quest-workbench.md), [0011](0011-talk-gestures.md))은 그대로. 맨 앞의 `<play>`/`<loop>`와 같다.
- 속도가 **배수**인 이유: 기본 속도를 바꿔도 대사가 그대로 맞다.

## 글자 소리: NPC의 `voice`

```json
"voice": "minecraft:block.note_block.bass"
"voice": { "sound": "minecraft:block.note_block.bass", "pitch": 0.8 }
```

- NPC마다 하나. 그 NPC가 하는 모든 말(인사말, 주고받는 퀘스트의 대사)에. 없으면 조용하다(옛 NPC 그대로).
- 아무 소리 이름: 바닐라 소리, 또는 리소스팩 `sounds.json`의 소리(클라이언트가 이름으로 재생한다,
  `SoundEvent.createVariableRangeEvent`). 없는 이름이면 조용하고 클라이언트 로그에 경고(`SoundEngine`). 리소스팩 소리는
  서버가 모르므로 publish는 모양만 검사한다(모델 이름과 같음).
- `pitch`는 비우면 1, 게임이 0.5~2.0으로 자르므로(`SoundEngine.calculatePitch`) 그 밖은 publish 거부. 짧은 꼴·긴 꼴은 대사 줄
  `animation`과 같은 규칙(0011). 크기·높낮이 흔들림은 나중에 없어도 되는 칸으로.
- 말 건 사람 화면에서만, 위치 없는 소리로. 음량은 마인크래프트 설정의 **음성/말소리**(`SoundSource.VOICE`).

## 그 밖 (쌈)

- 기본 속도: 1틱에 한 글자(초당 20자).
- 타이핑 중 클릭·Space·Enter: 그 페이지를 곧바로 다 보여줌(건너뛴 동작 표시는 마지막 것만 적용), 한 번 더 누르면 다음 페이지.
  ▼는 타이핑이 끝난 뒤에만.
- 소리는 글자마다, 빈칸·문장부호(. , ! ? … ~)는 조용히, 최소 2틱 간격. 문장부호에서 저절로 쉬지 않는다(작가가 `<pause>`).
- 모든 페이지가 타이핑된다. 스티브 화면은 동작 표시만 무시.
- publish 검사는 위치("몇 번째 글자 근처")와 함께 알린다. 에디터는 대사 줄 칸에 표시 끼워 넣기 버튼.

## 고르지 않은 것

- **중괄호 표시**(`{speed=…}`, Ren'Py): 값 넣기(`{player}`, 옛 `Format Text`의 `{name}`)와 한 괄호에 두 뜻이 된다. "`=`가 있으면
  연출"은 숨은 규칙이고 값 없는 연출(`{shake}`)과 구별이 안 된다. **대괄호**(Yarn Spinner): 한국어 글의 "[속보]"와 부딪친다.
  **구조로 쪼개기**(JSON 조각 배열, `/tellraw`): 한 문장이 여러 조각으로 흩어져 읽고 쓰기 어렵다. **기호 코드**(언더테일 `^1`): 외워야 한다.
- **닫는 표시**(`{cps=20}…{/cps}`): 짝을 맞춰야 해서 틀릴 곳이 는다.
- **속도를 글자/초로**: 기본을 바꾸면 모든 대사를 고쳐야 한다. **이름으로**(`slow`): 사이 값이 없다.
- **목소리를 대사 줄마다·따로 둔 목록에서**: 되풀이되거나 문서가 는다. **Lorebench가 준비한 목소리만**: 밖으로 못 나간다.
- **대사 안에서 다른 소리로 바꾸기**(속삭임·해설 목소리): 높낮이·크기까지 표시에 적으면 길어진다. 나중에 NPC 문서의 이름 붙인
  목소리 + `<voice=이름>`으로(roadmap B). **대사부터 BGM**도 roadmap B.
- **플레이어 글자 속도 설정**(느리게·빠르게·즉시, 포켓몬·페르소나·Ren'Py): 넣지 않는다(사용자, 언더테일처럼 작가의 리듬을
  지킨다). 급한 플레이어는 클릭으로 한 페이지를 바로 본다.
