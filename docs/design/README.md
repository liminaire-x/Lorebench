# 재설계 (design)

2026-10-02 시작. 퀘스트 문서 한 장에 보여주기·진행·대사·물건이 모두 몰려 꼬여 보였다(010 "늑대 무리"의 저절로 넘어가는
단계를 설계하다 드러남). 그래서 **큰 그림부터 설계를 다시 짠다.**

- **기준은 이 폴더.** 0001~0015의 결정 기록은 참고 자료(왜 그랬나, 무엇을 고르지 않았나)로 읽되 결론에 묶이지 않는다.
- **주제마다 한 장.** 이야기 하나보다 넓게 설계하되(사용자, 2026-10-02), 한 번에 한 주제만 다룬다.
- **주제마다 같은 순서**: 사례 비교 → 선택지 + 추천 + 고치는 비용 → 사용자 결정 → **종이 시험**(지금까지의 이야기 아홉 개와
  010으로 "이 모양에서 그대로 되나").
- **코드는 그대로 둔다.** 핵심 주제(장부·퀘스트·파일)가 정해진 뒤 조각 단위로 옮기거나 다시 만든다. 데이터는 첫 공개 전이라
  초기화한다.
- CLAUDE.md의 설계 약속(쉬운 말로 설명할 수 없으면 확정하지 않음, 고치는 비용, 같은 사실은 한 곳에만 …)은 그대로 지킨다.
