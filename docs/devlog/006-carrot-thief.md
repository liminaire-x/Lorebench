# 여섯 번째 이야기: 당근 도둑

2026-09-27 · 완성 2026-09-27 · 결정 [0014](../decisions/0014-typing.md)

## 장면

**말투가 캐릭터가 되는** 이야기: 한 글자씩 흘러나오는 대사, 그 안의 빠르기·쉼·몸짓, 캐릭터마다 다른 목소리. 설계는
[0014](../decisions/0014-typing.md).

1. 농부에게 말을 걸면 대사가 **한 글자씩**, 농부의 낮고 투박한 목소리("툭툭")와 함께 나온다.
2. "이 밭 좀 보게……"는 **천천히**, 농부는 밭을 **가리키며**(반복). "……"에서 **잠깐 멈춘다**.
3. 같은 페이지에서 이어서 "헉, 토끼들이 당근을 다 파먹었잖아!"는 **빠르게**, 동작은 **놀람**으로 바뀐다.
4. 타이핑 도중 클릭하면 그 페이지가 한 번에 다 보이고, 한 번 더 클릭하면 다음 페이지.
5. 퀘스트 `당근 도둑`(토끼 3마리 처치)을 제안받는다. 제안 대사의 마지막 페이지는 **소리 없이** 해설처럼: "* 농부의 한숨이 깊다."
6. 경비대장에게 말을 걸면 **다른 목소리**(높고 딱딱한 소리)가 난다.

## 콘텐츠

- NPC `농부`: 목소리 = 노트블록 베이스, 낮게. NPC `경비대장`: 목소리 = 노트블록 실로폰, 높게.
- 퀘스트 `당근 도둑`: 주는 NPC 농부, 목표 = 토끼 × 3 (처치형), 제안 대사에 속도·쉼·동작·소리 없음 표시, 보상 = 황금 당근 × 3.
- 에셋: chief 모델의 `shocked`(놀람, 한 번). `point`(가리키기, 반복)는 대화 몸짓 때 만듦.

## 조각

말투가 캐릭터가 되는 이야기. 타이핑 + 글 안 표시 + 글자 소리.

- [x] **0. 설계** (정함, 2026-09-27): [0014](../decisions/0014-typing.md). 글 안 표시는 꺾쇠 `<speed=배수>`·`<pause=초>`·`<play=…>`·
  `<loop=…>`·`<voice=none>`·`<voice>`(닫는 표시 없이 페이지 끝까지, 중괄호는 값 넣기 자리로 남김), NPC `voice`(아무 소리 이름 +
  `pitch`), 기본 초당 20자, 클릭하면 한 페이지를 다 보여줌, 플레이어 속도 설정은 넣지 않음.
- [x] **1. 타이핑과 표시**: 표시 읽기·검사(`Cues`, publish, 위치 알림, 테스트), 대화창 타이핑(`Typing`, 모든 페이지), 속도·쉼·동작,
  클릭하면 다 보여줌(건너뛴 동작은 마지막 것만), ▼는 끝난 뒤, 줄바꿈을 미리 계산해 단어가 튀지 않음. 에셋 `shocked`(서브에이전트,
  Blockbench). CI 그린(테스트 120), 게임 확인 완료(2026-09-27, 농부 인사말에 시험 줄): 한 글자씩, 느리게·쉼·빠르게, 가리키기 반복 →
  "헉"에서 놀람, 클릭하면 다 보임·놀람 자세로 끝남, 긴 줄 줄바꿈, 잘못된 표시 publish 거부, 기다리는 동안 아무것도 안 보임
  (A 바구니)·건너뛰기·Esc, Dev2 화면엔 동작 없음, 스티브는 타이핑만.
- [x] **2. 글자 소리**: NPC `voice` 칸(형식 테스트), 글자마다 소리(빈칸·문장부호 조용히, 최소 2틱, 기본 음량 0.5), `<voice=none>`·
  `<voice>`, 음성/말소리 음량. 대화 메시지 8. CI 그린(테스트 122), 게임 확인 완료(2026-09-27, 목소리는 publish API로 넣음): 농부 낮은
  베이스·경비대장 높은 실로폰, 빈칸·문장부호·쉼 동안 조용, 빠른 구간도 뭉개지지 않음, `<voice=none>` 해설 뒤 `<voice>`로 다시, 클릭해
  다 보이면 조용, 음성/말소리 막대로 조절·0이면 꺼짐, Dev2에게 안 들림, 목소리 없는 대장장이는 조용.
- [x] **3. 에디터**: 대사 목록마다 표시 버튼 한 줄(커서 자리에, 값은 선택된 채로), NPC 탭 Look에 Voice·Pitch 칸. 확인 중 버그
  (표시가 엉뚱한 줄 맨 앞에 들어감: 포커스 이벤트에만 기댐)를 찾아 고침. CI 그린(테스트 122), 확인 완료(2026-09-27, 에디터는 Claude가
  브라우저 패널로): Voice·Pitch 표시, 커서 자리에 넣고 값 덮어쓰기, 다른 묶음은 그대로, 빈 `<play=>` 거부·publish 뒤 유지, 게임에서
  에디터로 준 대장장이 목소리(기타)가 남.
- [x] **4. 이야기 조립**: 에셋 `shocked`(조각 1 때 서브에이전트), 에디터로 `당근 도둑`을 만들고 처음부터 끝까지(Dev1·Dev2). 에디터
  입력은 사용자 서버의 에디터에서 Claude가 직접, 농부 인사말의 시험 줄은 걷어냄. 게임 확인 완료(2026-09-27): 기다리는 동안 아무것도
  안 보이다가 제안이 낮은 목소리로 한 글자씩, 천천히·가리키기 → 쉼 → 빠르게·놀람, 둘째 페이지 보통, 셋째 페이지 소리 없는 해설 →
  카드, 클릭으로 건너뛰기, `토끼 처치 0/3`~`3/3`, 진행 중 대사, 기뻐하며 건네기·황금 당근, 경비대장 높은 목소리·대장장이 기타, Dev2 따로.
