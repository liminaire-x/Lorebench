# 다섯 번째 이야기: 대장장이의 내일

2026-09-27 · 완성 2026-09-27 · 결정 [0013](../decisions/0013-waiting.md)

## 장면

**시간이 흐르는 세계**: 맡기고, 기다리고, 다음 날 찾아가는 이야기. 설계는 [0013](../decisions/0013-waiting.md).

1. 마을에 **대장장이**가 서 있다. (촌장 모델)
2. 말을 걸면 "좋은 칼을 원하나? 철 5개를 가져오게." → [수락]하면 퀘스트 화면에 `철 주괴 0/5`.
3. 철 5개를 가져가면 "철은 다 모았군. 어디 보세." → [건네기]로 철을 건네면 "칼을 벼리는 데 하루는 걸리네. 내일 오게."
   퀘스트 화면엔 **기다리는 중**(며칠 남았는지는 보이지 않음).
4. 그날 다시 말을 걸면 "아직 망치질 중일세."
5. 아침이 오면(자고 일어나면 바로) 말을 걸자마자 "다 됐네! 받게."(기뻐함) → [받기]로 **대장장이의 칼**을 받는다.
6. 그 뒤로 말을 걸면 인사말만 한다. Dev2는 따로 처음부터.

## 콘텐츠

- NPC `대장장이`: 외형은 촌장 모델.
- 퀘스트 `칼 주문`: 주는 NPC 대장장이, 목표 = 철 주괴 × 5 (제출형), **기다림 = 1일**, 건넨 뒤·기다리는 중·다 됐을 때 대사,
  보상 = 대장장이의 칼(이름·인챈트, [0006](../decisions/0006-item-syntax.md)).

## 조각

맡기고, 기다리고, 다음 날 찾아가는 이야기. 퀘스트의 기다림 + 대사 칸 셋.

- [x] **0. 설계** (정함, 2026-09-27): [0013](../decisions/0013-waiting.md). 퀘스트 칸 `wait: { days }`(게임 날짜, 아침 6시에 넘어감),
  상태 `waiting` + 기록 `handed_<퀘스트 id>`(맡긴 날), 다 되면 보이는 상태 `ready`, 대사 `handed`·`waiting`·`ready`, 버튼 [받기],
  J 화면은 "기다리는 중"만.
- [x] **1. 기다림**: `wait` 칸(형식 테스트), [건네기] → 가져가고 `waiting` + `handed_`(`QuestWaits`, 테스트), 날짜가 지나면(또는
  뒤로 가면) `ready` → [받기]로 보상·완료(카드엔 보상만), 기다리는 동안 세지 않음, J 화면 "기다리는 중" → "받을 수 있습니다"(날이
  바뀌면 서버가 다시 보냄), 그래프 `Quest State` 갈래 `waiting`·`Complete Quest` 한 걸음, 조건 값 `waiting`, Reset이 `handed_`도
  지움, 에디터 Wait 칸·Players 표시. 메시지 버전 퀘스트 목록 5·대화 7. CI 그린(테스트 113), 게임 확인 완료(2026-09-27, 시험
  퀘스트 `기다림 시험`): Wait 칸 유지·잘못된 값 거부, 건네면 철만 사라짐, J 화면 기다리는 중, 자정은 안 셈·아침에 셈, 보상만 있는
  카드 [받기]/[나중에], Players 표시·Reset, `/time set day`로 날짜가 뒤로 가도 받음, Dev1·Dev2 따로, 옛 퀘스트는 곧바로 보상,
  노드 갈래·조건 목록에 `waiting`.
- [x] **2. 대사 칸 셋**: `handed`(건넨 직후, 서버가 기다리기 시작을 확인한 답장에 실음)·`waiting`(기다리는 중, 있어야 목록 줄이
  눌림)·`ready`(받기 전), 조건 묶음, 에디터 "With a wait" 칸 셋. 메시지 그대로. CI 그린(테스트 114), 게임 확인 완료(2026-09-27,
  `기다림 시험`): 칸 유지, 건넨 직후 대사 → 목록, 기다리는 중 줄이 눌려 대사 → 카드, 다음 날 받기 전 대사(기뻐함) → [받기], 비우면
  조각 1처럼, Dev2 그대로.
- [x] **3. 이야기 조립**: 코드 없이 에디터로 대장장이·`칼 주문`을 만들고 처음부터 끝까지(Dev1·Dev2). 에디터 입력은 사용자 서버의
  에디터에서 Claude가 직접. 게임 확인 완료(2026-09-27): 제안 → 수락 → `철 주괴 0/5`, 건네면 철만 사라지고 "내일 오게" → 기다리는 중,
  그날은 "아직 망치질 중일세", 아침이 오면 곧바로 "다 됐네!"(기뻐함) → [받기] → 대장장이의 칼(이름·날카로움 II), 그 뒤 인사말만,
  Dev2는 따로. 시험 퀘스트 `기다림 시험`은 지움.
