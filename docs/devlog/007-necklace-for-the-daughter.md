# 일곱 번째 이야기: 딸에게 가는 목걸이

2026-09-27 · 완성 2026-09-29 · 결정 [0015](../decisions/0015-quest-stages.md)

## 장면

**한 퀘스트가 여러 장면으로 흐르는** 이야기: 모으고, 보여주고, 맡기고, 기다리고, 전한다. 네 번째 이야기의 `목걸이 찾기`를
넓혀 고쳐 쓴다. 설계는 [0015](../decisions/0015-quest-stages.md).

1. 경비대장에게 말을 걸면 "늑대가 딸의 목걸이를 물고 달아났네. 조각이라도 찾아 주겠나?" → [수락]
   J 화면: `목걸이 찾기` · 할 일 **경비대장에게 조각 보여주기** · 목걸이 조각 0/3
2. 늑대를 잡아 조각 3개를 모아 경비대장에게 가면 "이건… 딸의 목걸이가 맞네!" → [보여주기] → "하지만 이대로는 줄 수 없군.
   대장장이에게 고쳐 달라고 해 주겠나?" 조각은 **플레이어가 그대로 갖고 있다**.
   J 화면: 지난 단계는 흐리게, 할 일 **대장장이에게 조각 맡기기** · 목걸이 조각 3/3
3. 대장장이에게 [건네기]로 조각을 맡기면 "섬세한 일이라 하루는 걸리네." J 화면: **기다리는 중**. 그날 다시 가면 "아직 손보는 중일세."
4. 다음 날 대장장이에게 가면 "다 됐네. 딸에게 전해 주게."(기뻐함) → [받기]로 **고친 목걸이**(퀘스트 전용 아이템)를 받는다.
   J 화면: 할 일 **딸에게 목걸이 전하기**
5. **경비대장의 딸**에게 목걸이를 건네면 "아버지가 찾아 주신 거예요? …고마워요!"(기뻐함) → 보상, 퀘스트 끝.
6. 그 뒤로 경비대장은 "목걸이 덕에 딸이 다시 웃는다네."
7. Dev2는 따로 처음부터. Dev1의 조각이나 목걸이를 건네받아도 Dev2에겐 쓸모가 없다.

## 콘텐츠

- NPC `경비대장의 딸`(새로): 외형은 촌장 모델, 목소리 = 노트블록 차임, 조금 높게. 인사말: 받기 전 "아버지가 요즘 걱정이
  많으세요.", 끝난 뒤 "아버지가 찾아 주신 목걸이, 매일 하고 다녀요!"
- NPC `경비대장`: 진행 중 인사말을 모든 단계에 맞게 "딸의 목걸이 일은 잘 되어 가나?"(기다리는 중에도). 인사말 조건은 아직
  단계를 보지 못한다(roadmap B).
- 퀘스트 `목걸이 찾기`(고쳐 씀, Dev1·Dev2의 옛 기록은 Reset): 주는 NPC 경비대장, 제안·거절 대사는 네 번째 이야기 그대로, 단계 셋:
  1. 경비대장에게 조각 보여주기: 목걸이 조각 × 3(늑대, 확률, **보여주기만**), 건넨 뒤 "대장장이에게…"
  2. 대장장이에게 조각 맡기기: 목걸이 조각 × 3(이미 가진 것), 기다림 1일, **주는 것** = 고친 목걸이(바다의 심장, 전용 아이템)
  3. 딸에게 목걸이 전하기: 고친 목걸이 × 1, 건네기 대사 첫 줄에 기뻐하기
  - 보상 = 에메랄드 × 5.
